# Sales Prediction Using Machine Learning

## Project Overview
This project uses Linear Regression to predict sales based on advertising spend.

## Objective
To understand the relationship between advertising expenditure and sales, and build a simple machine learning model for sales prediction.

## Dataset
The dataset contains two columns:
- `Advertising_Spend`: Money spent on advertising.
- `Sales`: Corresponding sales value.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression

## Project Workflow
1. Load the dataset.
2. Explore and understand the data.
3. Visualize the relationship between advertising spend and sales.
4. Train a Linear Regression model.
5. Evaluate the model and make predictions.

## Project Files
- `sales.csv` — Dataset
- `sales_prediction.py` — Python code

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn
```

Run the project:

```bash
python sales_prediction.py
```

## Learning Outcome
This project demonstrates a beginner-level machine learning workflow, from understanding data to training a model and making predictions.
